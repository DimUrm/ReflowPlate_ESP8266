Актуализированные детали обвязки (для печати/сохранения):

Твердотельное реле (SSR-25DA):
Клемма [3] (+) реле → → к пину D8 платы NodeMCU.
Клемма [4] (-) реле → → к общей GND платы NodeMCU.
Силовые клеммы [1] и [2] ставятся в разрыв провода Фазы 220V перед нагревателем.

Зуммер (Buzzer):
Плюс зуммера → → к пину RX (GPIO3) NodeMCU.
Минус зуммера → → к GND.

Термопара MAX6675:
Питание VCC модуля → → к 3.3V NodeMCU.
Земля GND → → к GND.
Вывод SO → → к D3.
Вывод CS → → к D4.
Вывод SCK → → к D0.
Металлическую гильзу термопары закрепить на алюминиевой плите с каплей термопасты.

Энкодер панели (KY-040):
Питание + → → к 3.3V (или 5V), 
GND → → к GND.
Вывод CLK → → к D5.
Вывод DT → → к D6.
Вывод SW (кнопка энкодера) → → к D7.
OLED дисплей (SSD1306):
Питание VCC → → к 3.3V или 5V, 
GND → → к GND.
Вывод SDA → → к D2.
Вывод SCL → → к D1.

Расширитель портов PCF8574:
Питание VCC → → к 5V, 
GND → → к GND.
Вывод SDA → → к D2 (параллельно дисплею).
Вывод SCL → → к D1 (параллельно дисплею).
Вывод P0 → → через резистор 100 Ом на затвор (Gate) N-канального мосфета кулера.
Вывод P1 → → резерв под реле вытяжки/света.

Кнопки передней панели («Back» и «Confirm»):

Первый контакт кнопки Back → → к выводу P2 платы PCF8574.

Первый контакт кнопки Confirm → → к выводу P3 платы PCF8574.
Вторые (общие) контакты обеих кнопок → → соединяются вместе и идут на GND.
Внешние резисторы не нужны: подтяжка к питанию включается программно внутри чипа PCF8574.
