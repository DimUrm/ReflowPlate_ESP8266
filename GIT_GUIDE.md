 Шпаргалка по работе с Git и GitHub
(Краткое руководство по управлению версиями и откату изменений)
📌 1. Как сохранить изменения (Новая точка сохранения)
Делайте сохранение каждый раз, когда добавили новую функцию, настроили пин или исправили баг.
Вариант через Терминал (Рекомендуемый):
Выполните 3 команды по очереди:
git add .
git commit -m "Понятное описание того, что изменили"
git push
git add . — собирает все измененные файлы проекта.
git commit -m "..." — делает локальный снимок (Save Game) с вашим комментарием.
git push — отправляет сохраненный снимок в облако на GitHub.
Вариант через интерфейс VS Code:
Слева нажмите на значок Source Control (Ctrl + Shift + G).
В поле сообщения сверху введите описание изменений (например: "Поправил ПИД").
Нажмите кнопку Commit (или галочку).
Нажмите синюю кнопку Sync Changes (Синхронизировать).
🚨 2. Как откатиться назад (Если всё сломалось)
Сценарий А: «Я только что испортил код и хочу вернуть всё, как было»
(Изменения еще не были закомичены, вы просто правили файлы руками)
Команда:
git restore .
Результат: все несохраненные правки во всех файлах мгновенно удаляются. Код возвращается к состоянию последнего успешного коммита.
Сценарий Б: «Я закомитил новую версию, но она не работает. Хочу вернуть прошлую!»
Посмотрите список ваших точек сохранения:
git log --oneline
Вам покажет историю версий с 7-значными номерами (хэшами):
b3c4d5e (HEAD -> main) Сломал работу энкодера
a1b2c3d Добавил спящий режим (РАБОЧАЯ ВЕРСИЯ!)
7f8e9d0 Initial commit: Smart Reflow Plate v2.4
Откатитесь на нужную рабочую версию (укажите её 7-значный код):
git reset --hard a1b2c3d
Принудительно обновите состояние в облаке на GitHub:
git push origin main --force
Результат: проект физически возвращается во времени назад к выбранной точке. Все сломанные файлы заменяются рабочими.
Сценарий В: «Сгорел жесткий диск / Сел за другой компьютер»
Как скачать проект с GitHub на новый чистый компьютер:
git clone https://github.com/ВАШ_ЛОГИН/ReflowPlate_ESP8266.git
Затем просто откройте скачанную папку в VS Code через File -> Open Folder.
🔍 3. Полезные команды для проверки
git status — показывает текущее состояние: какие файлы были изменены, а какие готовы к коммиту.
git diff — построчно показывает разницу (что именно вы дописали зеленым или удалили красным в файлах).
