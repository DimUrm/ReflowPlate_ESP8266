# 🔥 Smart Reflow Plate Controller (ESP8266 NodeMCU)

Профессиональный контроллер нагревательного столика для пайки SMD-компонентов на базе **NodeMCU (ESP8266)** с Wi-Fi, Web-интерфейсом, OLED-дисплеем и профилями JEDEC.

---

## ✨ Основные возможности:
- **Безопасное управление 220V:** Медленный ШИМ (1 сек) для твердотельных реле (SSR). Тройная защита: от обрыва термопары, перегрева и пожарный сторож `F_NO_RISE`.
- **Авто-профили пайки JEDEC:** Полноценный 4-стадийный термопрофиль (*Preheat -> Soak -> Reflow -> Cooldown*).
- **Хранение профилей в LittleFS (`/profiles.json`):** Редактирование времени и температур любого профиля прямо из браузера.
- **Web-интерфейс (GZIP):** Сжатый HTML5 интерфейс с живым графиком температуры на Canvas (работает офлайн).
- **Интеграция в Умный Дом:** Отправка всей телеметрии по протоколу **MQTT** (Home Assistant).
- **OTA-прошивка:** Обновление прошивки по воздуху с индикатором процентов прогресса прямо из браузера.
- **Энергоучет и статистика:** Подсчет потребленной энергии (Wh), счетчик циклов пайки и учет общего времени работы ТЭНа (моточасы).
- **Аппаратное расширение:** Поддержка I2C-расширителя **PCF8574** (авто-обдув кулером и физические кнопки `Back` / `Confirm`).
- **Защита OLED от выгорания:** Автоматическое гашение экрана через 15 минут бездействия.

## 🛠 Схема подключения (Hardware Pinout)

### 1. Подключения NodeMCU (ESP8266)
| Периферия | Пин NodeMCU | GPIO | Примечание |
| :--- | :---: | :---: | :--- |
| **SSR Реле (220V)** | `D8` | GPIO15 | Медленный ШИМ (окно 1 сек) |
| **Зуммер (Buzzer)** | `RX` | GPIO3 | ШИМ генератор tone() |
| **MAX6675 SO** | `D3` | GPIO0 | SPI Data (MISO) |
| **MAX6675 CS** | `D4` | GPIO2 | SPI Chip Select |
| **MAX6675 SCK**| `D0` | GPIO16 | SPI Clock |
| **Энкодер CLK** | `D5` | GPIO14 | Прерывание вращения |
| **Энкодер DT** | `D6` | GPIO12 | Направление |
| **Энкодер SW** | `D7` | GPIO13 | Кнопка энкодера |
| **I2C SDA** | `D2` | GPIO4 | Общая шина: OLED + PCF8574 |
| **I2C SCL** | `D1` | GPIO5 | Общая шина: OLED + PCF8574 |
| **NTC Термистор**| `A0` | ADC0 | Делитель 100k на GND (Опция) |

### 2. Расширитель портов PCF8574 (I2C: 0x20 / 0x27)
| Пин PCF | Назначение | Описание |
| :---: | :--- | :--- |
| **P0** | **Кулер охлаждения (Fan)** | N-Ch MOSFET к минусу кулера (Авто-обдув на Cooldown) |
| **P1** | **Вытяжка дыма / Свет** | Резервный силовой выход |
| **P2** | **Кнопка BACK** | Замыкает на GND (Стоп / Обдув / Сброс аварии) |
| **P3** | **Кнопка CONFIRM** | Замыкает на GND (Быстрая смена профилей по кругу) |

## 🚀 Сборка и прошивка (PlatformIO)
Проект настроен для сборки в среде **VS Code + PlatformIO**:
1. Клонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Нажмите **Build** (скрипт `version_bump.py` сам сожмет веб-морду в GZ и посчитает номер билда).
4. Прошейте плату по кабелю или загрузите `firmware.bin` через Web OTA.
